# Threat Detection

## Project Summary

This project documents my practical investigation into threat detection completed within a controlled TryHackMe laboratory environment. The project focused on recognising indicators of compromise, identifying suspicious activity and understanding how security analysts detect cyber threats.

## Environment

- TryHackMe Laboratory
- Simulated Enterprise Environment
- Security Monitoring

## Tools Used

- SIEM Concepts
- Security Logs
- Threat Intelligence
- Event Analysis
- Alert Monitoring

## Skills Demonstrated

- Threat Detection
- Security Monitoring
- Log Analysis
- Indicator of Compromise (IOC) Identification
- Event Correlation
- Security Documentation

## Investigation Activities

- Reviewed security alerts.
- Analysed suspicious events.
- Identified indicators of compromise.
- Correlated security events.
- Investigated unusual user activity.
- Documented investigation findings.

## Outcome

This project strengthened my understanding of threat detection and demonstrated how security analysts identify suspicious behaviour before it develops into a security incident.

## Key Findings

- Continuous monitoring improves threat detection.
- Indicators of compromise assist investigations.
- Log analysis provides valuable security evidence.
- Event correlation reduces false positives.
- Early detection reduces business impact.

## Reflection

Completing this project improved my understanding of identifying threats and analysing security events using structured investigation techniques.

## Business Impact

Early threat detection reduces organisational risk, limits business disruption and improves overall cyber resilience.

## Analyst Recommendations

- Continuously monitor security alerts.
- Investigate suspicious events promptly.
- Review indicators of compromise regularly.
- Improve detection rules.
- Maintain accurate investigation records.
- Review threat intelligence frequently.
