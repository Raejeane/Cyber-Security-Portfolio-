# Windows Endpoint Security Investigation

## Project Summary

This project documents a practical investigation of Windows endpoint security completed in a controlled TryHackMe laboratory environment.

## Environment

- Windows Operating System
- TryHackMe Lab

## Tools Used

- Event Viewer
- PowerShell
- Command Prompt
- Task Manager
- Windows Security

## Skills Demonstrated

- Windows Security
- Endpoint Investigation
- PowerShell
- Log Analysis
- Security Documentation

## Investigation Activities

- Reviewed Windows security settings and system protections
- Examined Windows event logs for security-related activity
- Used PowerShell and Command Prompt to inspect system information
- Reviewed running processes and system activity
- Documented findings using a structured security investigation approach

## Outcome

This project strengthened my understanding of Windows endpoint security and how analysts investigate Windows systems.
