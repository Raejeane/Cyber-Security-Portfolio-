
# Windows Endpoint Security Investigation

## Project Summary

This project documents a practical investigation of Windows endpoint security completed in a controlled TryHackMe laboratory environment.

## Environment

- Windows Operating System
- TryHackMe Lab

## Tools Used

- Event Viewer
- PowerShell
- Command Prompt
- Task Manager
- Windows Security

## Skills Demonstrated

- Windows Security
- Endpoint Investigation
- PowerShell
- Log Analysis
- Security Documentation

## Investigation Activities

- Reviewed Windows security settings and system protections
- Examined Windows event logs for security-related activity
- Used PowerShell and Command Prompt to inspect system information
- Reviewed running processes and system activity
- Documented findings using a structured security investigation approach

## Outcome

This project strengthened my understanding of Windows endpoint security and how analysts investigate Windows systems.

## Key Findings

- Reviewed Windows Defender security settings and endpoint protections.
- Examined Windows Event Viewer to identify security-related logs.
- Used PowerShell and Command Prompt to inspect system information.
- Reviewed running processes using Task Manager.
- Documented observations following a structured investigation process.

## Reflection
This investigation improved my understanding of Windows endpoint security, log analysis and the importance of structured documentation during security investigations. The practical experience strengthened my confidence using native Windows security tools commonly encountered in Security Operations Centre (SOC) environments.

## MITRE ATT&CK Techniques

Although this project focused on Windows endpoint investigation rather than a simulated attack, the investigation relates to common SOC activities including:

- T1082 – System Information Discovery
- T1059 – Command and Scripting Interpreter (PowerShell)
- T1012 – Query Registry
- T1047 – Windows Management Instrumentation (WMI)
