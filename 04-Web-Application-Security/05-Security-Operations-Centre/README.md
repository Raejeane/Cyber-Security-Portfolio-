# Security Operations Centre (SOC)

## Project Summary

This project documents my practical understanding of Security Operations Centre (SOC) operations developed through hands-on TryHackMe laboratory exercises. It demonstrates how SOC analysts monitor systems, investigate alerts and respond to security incidents to help protect organisational assets.

## Environment

- TryHackMe Laboratory
- Simulated Enterprise Environment
- Security Operations Centre (SOC)

## Tools Used

- SIEM Concepts
- Security Logs
- Threat Intelligence
- Event Analysis
- Incident Documentation

## Skills Demonstrated

- Security Monitoring
- Alert Investigation
- Log Analysis
- Threat Detection
- Incident Triage
- Analytical Thinking
- Security Documentation

## Investigation Activities

- Explored the role and responsibilities of a Security Operations Centre.
- Reviewed the stages of the incident response lifecycle.
- Investigated simulated security alerts.
- Examined security events using log analysis.
- Identified indicators of suspicious activity.
- Reviewed how analysts prioritise and escalate security incidents.
- Documented investigation findings and recommended actions.

## Outcome

This project strengthened my understanding of how Security Operations Centres operate and how analysts investigate, prioritise and respond to security incidents using structured investigation processes.

## Key Findings

- Continuous monitoring improves threat detection.
- Security logs provide valuable evidence during investigations.
- Incident prioritisation helps organisations respond efficiently.
- Accurate documentation supports effective communication and future investigations.
- Threat intelligence improves decision making during incident analysis.

## Reflection

Completing this project improved my understanding of the daily responsibilities of a SOC analyst and reinforced the importance of structured investigations, clear documentation and analytical thinking when responding to security events.

## Business Impact

An effective Security Operations Centre helps organisations detect threats quickly, minimise the impact of cyber attacks, reduce business disruption and strengthen overall security resilience.

## Analyst Recommendations

- Continuously monitor security alerts.
- Investigate suspicious activity promptly.
- Escalate incidents according to severity.
- Maintain detailed investigation records.
- Review monitoring rules regularly.
- Use threat intelligence to improve detection capabilities.
