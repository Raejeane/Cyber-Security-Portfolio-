# Web Application Security

## Project Summary

This project documents my practical investigation into web application security completed within a controlled TryHackMe laboratory environment. The investigation focused on understanding common web application vulnerabilities, how attackers exploit them and how security controls reduce risk.

## Environment

- TryHackMe Laboratory
- Linux Environment
- Web Application
- Web Browser

## Skills Demonstrated

- Web Application Security
- HTTP Fundamentals
- Authentication Concepts
- Input Validation
- Secure Coding Awareness
- Vulnerability Identification
- Security Documentation

## Investigation Activities

- Explored how web applications process user requests.
- Analysed the HTTP request and response process.
- Examined authentication and session management concepts.
- Investigated common web application vulnerabilities.
- Identified insecure user input and validation weaknesses.
- Reviewed methods used to improve web application security.
- Documented investigation findings and security recommendations.

## Outcome

This project strengthened my understanding of web application security principles and demonstrated how common vulnerabilities can affect confidentiality, integrity and availability if not properly mitigated.

## Key Findings

- Input validation is essential for preventing common attacks.
- Authentication should be implemented securely.
- Web applications should validate all user input.
- Security should be considered throughout development.
- Regular security testing helps identify vulnerabilities before exploitation.

## Reflection

Completing this project improved my understanding of how web applications operate, how attackers identify weaknesses and how security professionals reduce risk through secure development and regular testing.

## Business Impact

Secure web applications protect customer information, reduce organisational risk, improve business continuity and strengthen customer trust by reducing the likelihood of security incidents.

## Analyst Recommendations

- Validate all user input.
- Implement secure authentication.
- Apply the principle of least privilege.
- Keep applications updated.
- Perform regular vulnerability assessments.
- Monitor web application activity for suspicious behaviour.
