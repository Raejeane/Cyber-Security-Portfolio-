# Linux Security

## Project Summary

This project documents my practical investigation into Linux security completed within a controlled TryHackMe laboratory environment. The project focused on Linux administration, system security, user management and command-line operations commonly used by cybersecurity analysts.

## Environment

- TryHackMe Laboratory
- Linux Operating System
- Bash Terminal

## Tools Used

- Linux Terminal
- Bash Shell
- SSH
- File Permissions
- Linux Commands

## Skills Demonstrated

- Linux Administration
- Command Line Navigation
- File Management
- User Management
- File Permissions
- Process Management
- Security Documentation

## Investigation Activities

- Navigated the Linux file system using terminal commands.
- Managed files and directories.
- Reviewed Linux users, groups and permissions.
- Investigated running processes.
- Used common Linux commands for system administration.
- Applied file permission concepts.
- Documented investigation findings and security observations.

## Outcome

This project strengthened my understanding of Linux security fundamentals and demonstrated the practical skills required to investigate, manage and secure Linux systems.

## Key Findings

- Correct file permissions improve system security.
- Command-line skills are essential for security investigations.
- User account management reduces security risks.
- Linux provides powerful administrative tools.
- System monitoring assists with identifying suspicious activity.

## Reflection

Completing this project improved my confidence working within Linux environments and strengthened my understanding of how Linux systems are administered and secured in enterprise environments.

## Business Impact

Secure Linux administration reduces operational risk, strengthens system security and supports reliable business services through effective system management.

## Analyst Recommendations

- Apply least privilege permissions.
- Monitor user accounts regularly.
- Remove unnecessary services.
- Review system logs frequently.
- Keep Linux systems updated.
- Follow secure administration practices.
