# Phishing Analysis

## Project Summary

This project documents my practical investigation into phishing attacks completed within a controlled TryHackMe laboratory environment. The project focused on identifying phishing techniques, analysing suspicious emails and recognising common indicators used by attackers.

## Environment

- TryHackMe Laboratory
- Simulated Email Environment
- Security Awareness Investigation

## Tools Used

- Email Headers
- URL Analysis
- Threat Intelligence
- Browser Inspection
- Security Documentation

## Skills Demonstrated

- Phishing Analysis
- Email Investigation
- URL Analysis
- Threat Identification
- Security Awareness
- Investigation Documentation

## Investigation Activities

- Reviewed suspicious emails.
- Analysed sender information.
- Investigated embedded links.
- Identified phishing indicators.
- Assessed potential security risks.
- Documented investigation findings.

## Outcome

This project strengthened my understanding of phishing attacks and demonstrated practical techniques used to identify and investigate malicious emails.

## Key Findings

- Email headers provide valuable investigation evidence.
- Suspicious URLs often indicate phishing attempts.
- Social engineering targets human behaviour.
- User awareness reduces phishing success.
- Early reporting improves incident response.

## Reflection

Completing this project improved my ability to recognise phishing attacks and strengthened my investigative approach when analysing suspicious emails.

## Business Impact

Effective phishing detection reduces the risk of credential theft, malware infections and business disruption while improving organisational security awareness.

## Analyst Recommendations

- Verify suspicious email senders.
- Inspect URLs before opening links.
- Report suspected phishing immediately.
- Improve user security awareness.
- Implement email security controls.
- Review email filtering policies regularly.
