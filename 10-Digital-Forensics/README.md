# Digital Forensics

## Project Summary

This project documents my practical investigation into digital forensics completed within a controlled TryHackMe laboratory environment. The project focused on identifying, preserving and analysing digital evidence to support cybersecurity investigations.

## Environment

- TryHackMe Laboratory
- Windows Environment
- Digital Investigation Environment

## Tools Used

- Windows Event Viewer
- PowerShell
- Command Prompt
- Security Logs
- File System Investigation

## Skills Demonstrated

- Digital Forensics
- Evidence Collection
- Windows Investigation
- Log Analysis
- Security Documentation
- Analytical Thinking

## Investigation Activities

- Reviewed sources of digital evidence.
- Investigated Windows security logs.
- Examined system activity.
- Reviewed file system artefacts.
- Applied evidence preservation principles.
- Documented investigation findings.

## Outcome

This project strengthened my understanding of digital forensic investigations and demonstrated how evidence is collected, analysed and documented during cybersecurity investigations.

## Key Findings

- Digital evidence should be preserved throughout an investigation.
- Windows logs provide valuable forensic information.
- A structured investigation improves evidence integrity.
- Documentation supports accurate reporting.
- Evidence analysis assists incident investigations.

## Reflection

Completing this project improved my understanding of digital investigations and reinforced the importance of preserving evidence and following structured forensic procedures.

## Business Impact

Digital forensics enables organisations to understand security incidents, support legal and regulatory requirements and improve future security controls through evidence-based investigations.

## Analyst Recommendations

- Preserve evidence before making changes.
- Maintain a documented chain of investigation.
- Review security logs regularly.
- Follow structured forensic procedures.
- Secure collected evidence appropriately.
- Document all investigation activities.
