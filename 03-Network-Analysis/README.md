# Network Analysis

## Project Summary

This project documents my practical investigation into network analysis completed within a controlled TryHackMe laboratory environment. The investigation focused on understanding network communication, identifying suspicious traffic and analysing common network protocols.

## Environment

- TryHackMe Laboratory
- Simulated Enterprise Network
- Network Traffic Analysis

## Tools Used

- Wireshark
- TCP/IP
- DNS
- HTTP
- ICMP

## Skills Demonstrated

- Network Analysis
- Packet Inspection
- Protocol Analysis
- Traffic Investigation
- Network Troubleshooting
- Security Documentation

## Investigation Activities

- Analysed captured network traffic.
- Reviewed common TCP/IP protocols.
- Investigated DNS requests.
- Examined HTTP communication.
- Identified normal and suspicious network behaviour.
- Interpreted packet information.
- Documented investigation findings and observations.

## Outcome

This project strengthened my understanding of network communications and demonstrated how packet analysis assists security analysts when investigating network activity.

## Key Findings

- Packet analysis provides valuable evidence during investigations.
- Understanding protocols improves threat detection.
- DNS activity can reveal suspicious behaviour.
- Network monitoring supports early identification of security incidents.
- Traffic analysis improves incident investigations.

## Reflection

Completing this project improved my understanding of network communications and strengthened my ability to analyse traffic during cybersecurity investigations.

## Business Impact

Effective network monitoring helps organisations identify threats quickly, reduce downtime and strengthen overall security through continuous visibility of network activity.

## Analyst Recommendations

- Monitor network traffic continuously.
- Investigate unusual connections.
- Review DNS activity regularly.
- Maintain network visibility.
- Update network monitoring tools.
- Document investigation findings.
