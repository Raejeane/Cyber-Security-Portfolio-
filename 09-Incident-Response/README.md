# Incident Response

## Project Summary

This project documents my practical investigation into incident response completed within a controlled TryHackMe laboratory environment. The project focused on understanding how security incidents are identified, investigated, contained and resolved using a structured response process.

## Environment

- TryHackMe Laboratory
- Simulated Enterprise Environment
- Security Incident Investigation

## Tools Used

- Security Logs
- SIEM Concepts
- Incident Documentation
- Threat Intelligence
- Event Analysis

## Skills Demonstrated

- Incident Response
- Security Investigation
- Log Analysis
- Incident Documentation
- Threat Analysis
- Analytical Thinking

## Investigation Activities

- Reviewed the incident response lifecycle.
- Investigated simulated security incidents.
- Analysed security events and alerts.
- Identified indicators of compromise.
- Reviewed containment and recovery procedures.
- Documented investigation findings and recommendations.

## Outcome

This project strengthened my understanding of the incident response process and demonstrated the importance of structured investigations when responding to security incidents.

## Key Findings

- Early identification reduces the impact of security incidents.
- Accurate documentation supports effective investigations.
- Security logs provide valuable investigation evidence.
- Containment reduces the spread of threats.
- Lessons learned improve future response capabilities.

## Reflection

Completing this project improved my understanding of how security teams investigate, contain and recover from cyber incidents while maintaining accurate investigation records.

## Business Impact

An effective incident response process helps organisations minimise downtime, reduce financial impact and improve overall cyber resilience.

## Analyst Recommendations

- Respond to security incidents promptly.
- Maintain detailed investigation records.
- Review security logs regularly.
- Improve incident response procedures.
- Conduct lessons learned after every incident.
- Test incident response plans regularly.
